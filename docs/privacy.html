Privacy policy

Last updated: November 13, 2026

Paradox Town Uploader ("the tool") is a private publishing tool run by Axon Learning. It uploads videos we produce to YouTube channels that Axon Learning owns. This policy explains what data the tool uses.

YouTube API Services

The tool uses YouTube API Services. Google's handling of data is described in the Google Privacy Policy, and use of YouTube is subject to the YouTube Terms of Service.

What data the tool accesses

  • An OAuth authorization from the channel owner (a refresh token) with the YouTube upload permission, so the tool can upload videos and set their thumbnails on our own channels.
  • The information YouTube returns about the videos it uploads (video ID, upload and processing status), used to confirm that an upload worked.

The tool does not read, collect or store data about viewers, subscribers, comments, other channels or any other YouTube user.

How the data is used, stored and shared

  • The authorization is used only to upload our own videos and set their details and thumbnails.
  • It is stored as an encrypted secret in our private build settings and is never written to logs or shared.
  • Upload results (video ID and status) are kept in our build records to track what was published.
  • We do not sell, share or disclose any data to third parties.
  • No cookies or tracking are used by the tool or this site.

Deleting data and revoking access

The channel owner can revoke the tool's access at any time from the Google security settings page. When access is revoked or the tool is retired, we delete the stored authorization from our build settings within 7 days. To ask about or request deletion of any stored data, email us at the address below.
